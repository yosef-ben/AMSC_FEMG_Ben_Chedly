# Benchmark 17: Fisher-Kolmogorov equation on a connectome

> **Status:** preliminary application experiment. It predates the controlled
> one-dimensional validation in benchmark 18 and the verified 83-region
> FreeSurfer preprocessing in `data/connectome/fornari83/`. It is retained for
> reproducibility and will not be used as the final literature comparison.


## Goal

Apply the metric-graph finite element library to a deterministic
Fisher-Kolmogorov model for the spreading of misfolded proteins. The biological
model and time discretization follow Corti, Antonietti, Bonizzoni, Dede, and
Quarteroni. The spatial discretization is the P1 metric-graph FEM developed in
this project.

This benchmark is not a patient-specific reproduction of the reference paper:
the OASIS-3 PET data and the corresponding 246-node graph are not available in
the project. We use the public Budapest Reference Connectome and a documented
synthetic initial concentration.

## Domain

The preprocessing step extracts the largest connected component of the public
Budapest graph:

```text
467 vertices
980 edges
```

Self-loops and disconnected vertices are excluded. Every edge is represented
as a unit metric interval with one P1 finite element in this first run.

The numerical metric length and the anatomical display coordinates are kept
separate. The latter are taken from the official Budapest viewer. Its 83-region
atlas assigns one pial coordinate to each parent region; consequently, the 467
fine graph nodes retained here are displayed at 75 distinct parent-region
locations, as in the public viewer.

## Mathematical problem

On every metric edge `e`, solve

```text
partial_t c - partial_s(D_e partial_s c) = alpha c (1-c).
```

The concentration is continuous at graph vertices and the weighted Kirchhoff
condition is imposed naturally by the weak formulation:

```text
sum_(e incident to v) D_e partial_(n_e) c_e(v,t) = 0.
```

The FEM semi-discrete problem is

```text
M C_dot + K_D C = R(C),
R_i(C) = integral_Gamma alpha c_h (1-c_h) phi_i.
```

The nonlinear vector and Jacobian are assembled with three-point
Gauss--Legendre quadrature on every cell. This rule integrates exactly the
degree-four element integrands generated by P1 concentration and reaction
coefficient fields. The reaction is therefore a consistent finite element
integral rather than a nodal Hadamard product.

## Time discretization

As in Corti et al., diffusion and the first concentration factor in the
reaction are treated with Crank--Nicolson. Only the saturation factor is
extrapolated:

```text
C_star = 3/2 C^n - 1/2 C^(n-1),
G(C_star)_ij = integral_Gamma alpha (1-c_star) phi_i phi_j,

(M + dt/2 K_D - dt/2 G(C_star)) C^(n+1)
  = (M - dt/2 K_D + dt/2 G(C_star)) C^n.
```

At the first step, `C^(-1)=C^0` initializes the extrapolation. Since
`G(C_star)` changes with time, the sparse time-step matrix is assembled and
factorized at every step.

## Deterministic coefficients

The stochastic parameters of the reference work are replaced by their
estimated means from Table 1:

```text
Frontal lobe          0.1801
Temporal lobe         0.1421
Parietal lobe         0.0627
Insular lobe          0.1005
Limbic lobe           0.1351
Occipital lobe        0.0545
Subcortical nuclei    0.1147
```

FreeSurfer parcel names in the Budapest dataset are deterministically mapped
to these seven groups. The nodal coefficient is linearly interpolated along
each metric edge.

The graph connectivity weight `w_e` is converted into an edge diffusivity by

```text
D_e = w_e / max(w).
```

This preserves relative connectivity while making the diffusion scale
dimensionless and explicit. It is a modelling choice for the Budapest graph,
not a calibrated parameter from the patient-specific study.

## Initial condition and parameters

The unavailable PET projection is replaced by an Alzheimer-like synthetic
seed. Entorhinal and hippocampal vertices start from `c=0.10`; all other
vertices start from `c=0.01`.

```text
T                = 20 years
dt               = 0.2 years
time method      = CN with extrapolated reaction
elements/edge    = 1
output interval  = 1 year
```

## Verification

Before running the connectome case, the implementation is tested using a
spatially uniform datum and coefficient. Diffusion then vanishes and the exact
solution is the scalar logistic curve. Temporal refinement gives the expected orders:

```text
method                  dt       error         rate
Corti semi-implicit     0.010    2.95864e-08   1.99918
Corti semi-implicit     0.005    7.39836e-09   1.99966
Backward Euler          0.010    1.64514e-05   1.00144
Backward Euler          0.005    8.22363e-06   1.00036
```

## Result

The initial global mean is `0.0109636`. At `T=20`, the global mean is
`0.1750958` and the nodal concentration range is:

```text
[0.0268164, 0.611601]
```

The numerical concentration remains in the physical interval `[0,1]` for the
whole simulation. Regional averages are stored in `results/regional_averages.csv`.

## Reproduce

From the project root:

```bash
python3 scripts/prepare-budapest-connectome.py
python3 scripts/prepare-budapest-anatomy.py --download
cmake -S . -B build
cmake --build build --target test_fisher_kolmogorov_logistic
cmake --build build --target test_fisher_kolmogorov_connectome
./build/test_fisher_kolmogorov_logistic
./build/test_fisher_kolmogorov_connectome
```

## Anatomical visualization in ParaView

Open both files and click `Apply`:

```text
data/connectome/anatomy/brain_surface.vtk
output/fisher_kolmogorov/connectome/solution.pvd
```

For `brain_surface.vtk`, select `Surface`, use
a light-gray solid color, and set `Opacity` to approximately
`0.15-0.25`. For `solution.pvd`, color by
the point field `c` and set `Line Width` to
`2-3`. Then use `Reset Camera` and select
the desired time from the animation toolbar. A small Tube radius may be used
for a publication figure, but it is not required to recognize the connectome.

The graph is now drawn in the same anatomical coordinate system as the pial
surface. The numerical fields are `c` and
`alpha` on points and `diffusion` on
cells. These display coordinates do not enter the FEM assembly.

## Literature verification

Checked against Corti, Antonietti, Bonizzoni, Dede and Quarteroni, sections 2.1
and 4, table 1.

Confirmed:

- The seven estimated reaction means quoted above are exactly the `mu_l` column
  of table 1 of the paper.
- The time discretization implements equation (4) of the paper exactly: the
  diffusion and the first concentration factor are centred in time, only the
  saturation factor is extrapolated with `3/2 c^k - 1/2 c^(k-1)`, and the first
  step is started from `c^(-1) = c^0`.
- The paper uses `dt = 2e-1` for its simulations, which is the step used here.
- The logistic verification table was regenerated in this working copy and
  reproduces exactly, including the observed orders `1.99918` and `1.99966` for
  the semi-implicit scheme and `1.00144` and `1.00036` for Backward Euler.

Deviations, all documented above and forced by data availability: the 467-node
Budapest largest connected component instead of the patient-specific 246-node
Brainnetome graph, and a synthetic seed instead of the PET projection.

This benchmark remains superseded by benchmark 21, which uses the audited
83-region graph of benchmark 19 with the same model and coefficients. Nothing
found during the verification pass changes that status.
